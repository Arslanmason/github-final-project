# github-final-project
## Simple Interest Calculator

A simple open-source bash script project to calculate simple interest.

### Description
This project calculates simple interest based on the principal amount, the annual rate of interest, and the time period in years. It was created as part of the Introduction to Git and GitHub course to demonstrate version control workflows, repository management, and open-source contribution best practices.

### Usage
Run the script in a bash environment:
```bash
./simple-interest.sh
```
Follow the prompts to enter the Principal, Rate, and Time.
